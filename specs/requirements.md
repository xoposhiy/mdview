# mdview — Markdown Viewer for Windows

Быстрый просмотрщик Markdown-файлов для Windows.

## Основные требования

- **Мгновенный запуск** — минимальное время до первого рендера
- **Рендеринг Markdown** — таблицы, блоки кода с подсветкой синтаксиса, изображения, GFM
- **Отслеживание изменений** — автоматическая перезагрузка при изменении файла на диске
- **Открыть в редакторе** — кнопка/хоткей открывает файл в `%EDITOR%` (или `notepad` по умолчанию)
- **Файловая панель** — боковое дерево папок/файлов слева, навигация по `.md`-файлам рядом
- **Размер шрифта** — увеличение/уменьшение через хоткеи (`Ctrl++` / `Ctrl+-`)
- **Темы** — светлая и тёмная тема, переключение через хоткей или кнопку

## Технический стек

- **Runtime**: Go 1.22+
- **Рендеринг**: WebView2 (системный Edge, предустановлен на Win 10/11)
- **Парсер MD**: goldmark (GFM-совместимый)
- **Подсветка**: chroma (200+ языков, нативный Go)
- **Файловый watcher**: fsnotify

## Использование

```
mdview README.md
```

## Хоткеи

| Действие             | Хоткей              |
|----------------------|---------------------|
| Открыть в редакторе  | `Ctrl+E`            |
| Показать/скрыть дерево | `Ctrl+B`          |
| Увеличить шрифт      | `Ctrl++`            |
| Уменьшить шрифт      | `Ctrl+-`            |
| Сбросить шрифт       | `Ctrl+0`            |
| Переключить тему     | `Ctrl+T`            |
| Перезагрузить        | `F5` / `Ctrl+R`     |
| Выход                | `Escape`            |
