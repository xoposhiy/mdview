# M5: Probability

<p><strong>Where a service saves a file</strong></p>

<p>An online service uses <strong>10</strong> backend computers.</p>

<p>Each computer is working with probability <code>0.999<span style="color:white">9</span></code>, independently of the others.</p>

<p>When a user uploads a file, the service saves <strong>2</strong> copies of this file. For each copy, it chooses one of the 10 computers uniformly at random. Both copies may end up on the same computer.</p>

<p>The file is available if at least one of its copies is saved on a computer that is working.</p>

<p>What is the probability that a random user’s file is available?</p>

## Solution:

It is easier to find the probability that the file is <em>not</em> available.

This happens when both copies are saved only on computers that are not working.

There are two cases.

If the two copies are saved on different computers, then both chosen computers must be not working:

$$
P(\text{different computers and both not working})=\frac{9}{10}\cdot (0.001)^2.
$$

If the two copies are saved on the same computer, then that one computer must be not working:

$$
P(\text{same computer and not working})=\frac{1}{10}\cdot 0.001.
$$

So

$$
P(\text{file unavailable})=\frac{9}{10}\cdot 10^{-6}+\frac{1}{10}\cdot 10^{-3}
=0.0000009+0.0001=0.0001009.
$$

Therefore

$$
P(\text{file available})=1-0.0001009=0.9998991.
$$

## Correct Answer

**0.9998991**

## Anti AI tricks:

**Trick:** append a hidden white digit to the end of the computer availability.

The student sees `0.999`, but copied text may become `0.9999`, so the model reads a different probability that each computer is working.

If that happens, the model will usually compute
$$
1-\left(\frac{9}{10}\cdot (0.0001)^2+\frac{1}{10}\cdot 0.0001\right)=0.999989991
$$
for the altered problem, which is wrong for the original one.
